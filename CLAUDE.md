## README Maintenance

After creating a new agent file or recording eval results, always update the Agents table in README.md to reflect the current best agent and all known win rates. The best agent should be bolded in the table. Also update `AGENT` and `RENDER_AGENT` in the Makefile to point to the current best agent.

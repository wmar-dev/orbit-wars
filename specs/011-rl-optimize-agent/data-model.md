# Data Model: RL-Optimized Agent

**Branch**: `011-rl-optimize-agent` | **Date**: 2026-05-31

## Entities

### OrbitWarsEnv

Gymnasium-compatible wrapper over the kaggle-environments `orbit_wars` trainer API.

| Field | Type | Description |
| ----- | ---- | ----------- |
| opponent | str or callable | Agent to train against; `"random"`, path to agent file, or callable |
| trainer | kaggle Trainer | Internal trainer handle; recreated on each `reset()` |
| observation_space | Box(319,) float32 | Fixed-size encoded observation vector |
| action_space | MultiDiscrete([12, 12, 5]) | Factored source/target/fraction heads |
| _step | int | Current turn within episode |

**State transitions**: `reset()` → `step()` × N → `done=True` → `reset()`

**Validation**: `step()` must receive a valid 3-element action; invalid source/target combinations are handled by the action mask at the policy layer, not by the env.

---

### ObsEncoder

Stateless encoding function: raw kaggle observation → fixed-size numpy vector + action mask.

**Input**: `obs` (kaggle observation object with `.planets`, `.fleets`, `.comets`, `.initial_planets`, `.angular_velocity`)

**Output**: `(np.ndarray[319, float32], np.ndarray[52, bool])`

Observation vector layout:

| Segment | Indices | Size | Content |
| ------- | ------- | ---- | ------- |
| Planets | 0–83 | 84 | 12 slots × 7 features: owner_self, owner_enemy, owner_neutral, x/100, y/100, ships/500, production/10 |
| Fleets | 84–233 | 150 | 30 slots × 5 features: owner_self, owner_enemy, owner_neutral, x/100, y/100 |
| Comets | 234–263 | 30 | 10 slots × 3 features: x/100, y/100, ships/500 |
| Globals | 264–266 | 3 | player_id/3, angular_velocity×10, turn/200 |
| Masks | 267–318 | 52 | Boolean: 1=slot occupied, 0=padded |

Action mask (52 bools): first 12 are source-valid flags (True if player owns that planet slot and has surplus ships), next 12 are target-valid flags (True if target != source), last 28 unused (reserved for future extension).

### PolicyNetwork

PyTorch MLP with three output heads for factored action selection.

| Layer | Shape | Activation |
| ----- | ----- | ---------- |
| Input | 319 | — |
| Hidden 1 | 256 | ReLU |
| Hidden 2 | 256 | ReLU |
| Source head | 12 | — (masked softmax at sample time) |
| Target head | 12 | — (masked softmax at sample time) |
| Fraction head | 5 | — (softmax) |
| Value head | 1 | — (PPO/A2C critic) |

**Action masking**: source and target logits have −1e9 added at invalid positions before softmax. No masking applied to fraction head.

**Inference (numpy)**: Weights exported as `{layer_name: np.ndarray}`. Forward pass implemented as matrix multiplications with ReLU activations; argmax over masked logits gives the discrete action.

---

### Checkpoint

Saved state for training resumption and opponent pool management.

| Field | Type | Description |
| ----- | ---- | ----------- |
| policy_state_dict | dict | PyTorch `state_dict` of PolicyNetwork |
| episode | int | Episode number at save time |
| score_vs_v38 | float or None | Win rate vs agent_v38 at this checkpoint (None if not yet evaluated) |
| algorithm | str | `"ppo"`, `"dqn"`, or `"a2c"` |

**File naming**: `rl/checkpoints/{algorithm}_ep{episode:05d}.pt`
**Best checkpoint**: `rl/checkpoints/{algorithm}_best.pt` (symlink or copy of highest `score_vs_v38`)

### ExportedAgent

A self-contained `agent_vNN.py` file at repo root. Generated by `rl/export.py`.

| Section | Content |
| ------- | ------- |
| `WEIGHTS_B64` | Base64-encoded pickle of `{layer_name: np.ndarray}` weight dict |
| `_weights` | Module-level decoded numpy weight arrays (decoded once at import) |
| `_forward(x)` | Numpy reimplementation of PolicyNetwork forward pass |
| `agent(obs, config)` | Kaggle entry point: encodes obs → runs `_forward` → decodes action → returns fleet commands |

**Self-containment check**: File imports only from `math`, `numpy`, `base64`, `pickle`, `collections` (all stdlib or numpy). Zero imports from project-local modules.

### ExperimentRecord

Markdown file in `experiments/` documenting each RL training run.

**File naming**: `experiments/011-rl-{algorithm}-baseline.md`

**Required fields**:
- **Hypothesis**: Expected improvement and why
- **Algorithm**: PPO / DQN / A2C
- **Hyperparameters**: Learning rate, batch size, episodes, hidden size, γ, λ (PPO only)
- **Training curve**: Episode vs. reward summary (can be inline table or chart description)
- **Self-play result**: Score vs agent_v38 over 50 games (seeds 0–49)
- **Safety audit**: Sun/OOB loss count from `diagnose_v9.py`
- **Conclusion**: Pass/fail, what was learned, whether to submit

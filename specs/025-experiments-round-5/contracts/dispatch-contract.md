# Contracts: Experiments Round 5

## Internal API Contracts

This document describes the internal interfaces between dispatch components in agent_v65.py.

### 1. Dispatch Contract

```python
# Input: Greedy dispatch entry
(move: [src_id, angle, ships])

# Output: Structured dispatch
(dispatches: [(src_id, target_id, ships, eta)])
```

**Producers**: `_greedy_moves`, `_gen_beam_candidates`
**Consumers**: `_beam_search`, `_apply_dispatches`, `_dispatches_to_moves`

---

### 2. Fleet Size Contract

```python
# Input
target: Planet        # Target planet
x_pred, y_pred: float # Predicted position at arrival
mine_x, mine_y: float # Source position
angular_velocity: float
initial_planets_map: dict

# Output  
(ships_needed: int, x_pred_final: float, y_pred_final: float)
```

**Owner**: `_enemy_fleet_size`
**Applies to**: Enemy planets and (after P2) neutral planets

---

### 3. Beam Candidate Contract

```python
# Combined candidate tuple (P1)
(combined_dispatches: [(src_id, target_id, ships, eta), ...], 
 combined_moves: [[src_id, angle, ships], ...])
```

**Generated by**: `_gen_beam_candidates` (in P1, adds multi-source entries)
**Consumed by**: `_beam_search` (evaluates via simulation)
**Guarantees**: Each dispatch correctly reduces source planet ships in sim state via `_apply_dispatches`

---

### 4. State Adaptation Contract (P3)

```python
opponent_count = len(set(p.owner for p in planets if 0 <= p.owner != player))
gff_mult = {
    3: 1.2,   # defensive (3 opponents alive → 4-player FFA)
    2: 1.0,   # balanced (2 opponents alive → 3-player)
    1: 0.8,   # aggressive (1 opponent alive → endgame)
}.get(opponent_count, 1.0)
```

**Applied in**: `_greedy_moves` during `gff` computation
**Controls**: Garrison floor factor, splinter window, aggressiveness
